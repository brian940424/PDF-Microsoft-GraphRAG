# 安裝與啟動

## 本機環境

建議使用 Python 3.12（最低需求 Python 3.11）。在專案根目錄建立虛擬環境並安裝：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e ".[test]"
```

Linux／WSL 可直接執行管理後台啟動腳本：

```bash
chmod +x start.sh   # 首次需要時執行
./start.sh
```

`start.sh` 預設使用 `.venv`、將資料存入專案下的 `projects/`，並在伺服器就緒時嘗試開啟瀏覽器。若要停用自動開啟瀏覽器：

```bash
OPEN_BROWSER=0 ./start.sh
```

開發時可啟用自動重啟模式：`src/` 下任何 `.py` 檔變更後，腳本會自動重啟管理後台，瀏覽器重新整理即可看到新版本。若程式啟動失敗，會等下一次原始碼變更再重試。

```bash
DEV_RELOAD=1 ./start.sh
```

也可直接呼叫入口：

```bash
.venv/bin/automotive-graphrag-admin
.venv/bin/automotive-graphrag
```

預設 Gradio 位址為 `http://127.0.0.1:7860`。若管理後台和一般使用者入口同時執行，請為其中一個設定不同連接埠，例如：

```bash
GRADIO_SERVER_PORT=7861 .venv/bin/automotive-graphrag-admin
```

兩個入口應指向相同 `PROJECTS_ROOT`，才會讀取同一批專案資料。

## API 設定

可在管理後台「0 專案與連線設定」的連線設定區塊設定並儲存，也可在啟動前設定環境變數：

```bash
export GRAPHRAG_API_KEY="your-api-key"
export GRAPHRAG_API_BASE="https://api.openai.com/v1"
export GRAPHRAG_CHAT_MODEL="gpt-6-luna"
export GRAPHRAG_EMBEDDING_MODEL="text-embedding-3-small"
```

或在專案根目錄建立本機 `.env`（勿提交至版本控制）：

```dotenv
GRAPHRAG_API_KEY=your-api-key
GRAPHRAG_API_BASE=https://api.openai.com/v1
GRAPHRAG_CHAT_MODEL=gpt-6-luna
GRAPHRAG_EMBEDDING_MODEL=text-embedding-3-small
```

模型與 API 供應商需相容於 Microsoft GraphRAG 使用的 Chat／Embedding 介面。金鑰不應寫入程式碼、Dockerfile 或公開映像。

## Docker

建置映像：

```bash
DOCKER_BUILDKIT=1 docker build --progress=plain -t automotive-graphrag:local .
docker volume create automotive-graphrag-data
```

啟動管理後台：

```bash
docker run --rm --name automotive-graphrag-admin --env-file .env \
  -p 7861:7860 -v automotive-graphrag-data:/app/projects \
  automotive-graphrag:local automotive-graphrag-admin
```

啟動一般使用者入口：

```bash
docker run --rm --name automotive-graphrag-portal --env-file .env \
  -p 7860:7860 -v automotive-graphrag-data:/app/projects \
  automotive-graphrag:local
```

兩個容器必須掛載同一個資料 Volume。管理介面位於 `http://localhost:7861`，一般入口位於 `http://localhost:7860`。正式環境需使用反向代理提供 TLS、登入驗證與權限控管。

## 測試

安裝 `.[test]` 後執行：

```bash
.venv/bin/pytest -q
```

只執行檢索實驗測試：

```bash
.venv/bin/pytest -q tests/test_retrieval_experiments.py
```

測試使用替身 Runner／Client，不會呼叫實際模型 API。
