## 分支與範圍

分支：`refactor/major-overhaul`

本分支調整 Gradio 管理後台的專案操作方式，加入逐份 PDF 前處理設定、即時建圖日誌，以及單次問答收藏題目集功能。

## 改動摘要

- 「專案設定」可建立、刪除、選取並開啟專案。開啟後，其餘管理頁面共用此專案，不再各自選擇專案。
- 「連線設定」可讀取環境變數、已儲存設定及 `.env`。讀取順序為環境變數、`PROJECTS_ROOT/.connection.json`、最後才是 `.env`，避免舊的專案 `.env` 蓋過新儲存的 API Key。
- 「文件與建圖」可為每份 PDF 個別設定頁首／頁尾忽略比例，以及起訖頁索引。比例預設為 0%，頁面索引從 0 開始且包含結束頁；預設範圍為第 0 頁到最後一頁。
- GraphRAG 建圖日誌會即時串流到頁面，日誌更新時自動捲至最底。
- 「問答測試」只保留單次問答。使用者可建立或載入目前專案的題目集，編輯系統回答後，將問題及修改後答案一起加入題目集。新增項目會保存於 `question`、`reference_answer` 與 `answer` 欄位，沒有答案時不允許加入。題目集區塊位於 Evidence 詳情上方。
- 修正開啟專案時的回呼輸出數量不符，以及章節下拉選單型別錯誤。
