# 文件目錄

專案說明文件集中放在此資料夾。安裝、啟動、Docker 部署與常見問題請見根目錄的 [README.md](../README.md)；開發規範（提交、測試、LLM prompt 語言、文件維護）請見根目錄的 [AGENTS.md](../AGENTS.md)。

## 建議閱讀順序

新加入的組員或 agent 建議依序閱讀：

1. [../README.md](../README.md)：專案功能、資料流程、安裝與啟動
2. [功能總覽.md](功能總覽.md)：管理後台 0-0 至 0-5 各頁功能與專案資料結構
3. [改善計畫.md](改善計畫.md)：各改善項目的狀態、做法與驗收標準
4. [交接紀錄.md](交接紀錄.md)：前一次重大整改分支的改動與驗證情況

## 維護規則

- 新增說明文件時放在 `docs/`，並在上方清單補一列。
- 根目錄只保留 `README.md` 與 `AGENTS.md`；`AGENTS.md` 必須留在根目錄，agent 工具才會自動讀取。
- 移動或改名文件時，同步更新本清單與其他文件中的連結。
- 改善項目的狀態變更記錄在 [改善計畫.md](改善計畫.md)；工作告一段落但未完成時，更新 [交接紀錄.md](交接紀錄.md)。
