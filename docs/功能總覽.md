# 新版功能總覽

本文件介紹管理後台目前提供的主要功能。頁面採用編號方便參照；一般使用者入口另行啟動，並與管理後台共用專案資料。

## 管理後台

### 0 專案與連線設定

建立、刪除、選取並開啟專案。刪除會移除該專案全部資料；開啟後，文件、問答、題目集及實驗操作均以該專案為作用範圍。

同頁的「GraphRAG 共用連線設定」區塊可設定所有專案共用的 API Base URL、API Key、Chat 模型與 Embedding 模型，並可測試 API 連線。API Key 可由環境變數或 `.env` 預先提供，也可在此頁儲存；請勿將金鑰提交到 Git。

### 1 文件與建圖

- 匯入或刪除 PDF（在「選擇要前處理／建圖的 PDF」選取後按「刪除所選 PDF」，會跳出確認框），檢視頁數、前處理狀態與錯誤資訊；Documents 表的「前處理」「建圖」欄位標示每份 PDF 是否已前處理、是否已納入目前的圖譜。
- 每份 PDF 可分別設定忽略頁首／頁尾百分比，以及起始／結束頁。頁面索引從 0 起算，結束頁包含在處理範圍內；預設忽略比例為 0%，頁面範圍為全文。
- 執行 PyMuPDF 前處理及 Microsoft GraphRAG 建圖，兩者都有進度條；建圖日誌會即時更新並自動捲至最新內容。
- 可多選 PDF 只重新前處理這些檔案（其他檔案保留原結果）；建圖時會先前處理所選但尚未前處理的 PDF，再以所有已前處理的 PDF 重建整個專案圖譜（GraphRAG 圖譜為整個專案共用）。
- 可選擇建圖模型。建圖工作時間取決於文件規模、API 與硬體資源。

### 2 問答測試

輸入單一問題，選擇回答模型、GraphRAG 查詢策略及回答格式。查詢方法預設為「自動」：先由回答模型依問題類型選擇 Local／Global／DRIFT／Basic，查詢資訊會顯示實際使用的策略與選擇原因；判斷失敗時改用 Local 並註明原因。完成後可檢視／編輯回答、查詢資訊、檢索來源及 Evidence 原文，來源資訊包含文件、頁碼與 Chunk 等可取得欄位。

### 3 自動問答測試

以匯入或已保存的題目集進行自動化問答流程：

1. 設定每份 PDF 的題數、生題模型與是否允許不同 PDF 平行生題。
2. 生成題目與來源後，可檢視、編輯問題、正確答案及來源欄位，並匯出題目集 JSON。
3. 獨立設定回答模型、檢索模式、回答格式及請求並行數，按鈕執行回答。
4. 回答完成後再執行評測；評測模型和並行數獨立設定。可人工修改判斷，系統會清空舊評判理由並重算正確率。

### 4 檢索實驗

匯入一份或多份題目集，以同一題目資料比較多個實驗組。每組可自行設定名稱、回答模型、Local／Global／DRIFT／Basic 策略、回答格式，以及策略專屬參數。Luna 模型可設定推理深度。評測模型、評分方式和最大並行數為全域設定。

實驗可分別執行回答與評測、停止並保留已完成題目；頁面提供實驗組摘要、實驗組 × 題目集摘要及逐題結果。逐題評測等級為 0 錯誤、1 部分對、2 全對，可人工修正並更新摘要。結果可匯出精簡摘要 JSON 與逐題結果 JSON。

策略參數、指標定義與執行注意事項見[檢索實驗與策略參數](檢索實驗與策略參數.md)。

## 一般使用者入口

`automotive-graphrag` 提供已啟用且完成建圖專案的問答介面。使用者選擇專案、輸入問題後，可查看回答和系統取回的 Evidence 詳情。這是與管理後台分開啟動的入口；正式部署時應在外部加入身分驗證與存取控制。

## 專案資料與保存

每個專案資料夾彼此隔離，主要內容如下：

```text
projects/<project_id>/
├── source/          # 原始 PDF
├── processed/       # 前處理文字與來源資訊
├── graphrag/        # GraphRAG 設定、索引與建圖日誌
├── question_sets/   # 匯入及保存的題目集
├── runs/            # 問答、測試與實驗狀態
└── exports/         # 匯出結果
```

重新載入同一個專案時，題目集、自動問答測試狀態、實驗組設定及最近一次實驗結果會從專案資料中還原。API 連線設定是 `PROJECTS_ROOT` 下共用資料，請妥善保護。
