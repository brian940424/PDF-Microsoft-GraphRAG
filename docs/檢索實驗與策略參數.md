# 檢索實驗與策略參數

「4 檢索實驗」用相同的題目集比較 Microsoft GraphRAG 的 Local、Global、DRIFT、Basic 四種查詢方式。每個實驗組可個別設定回答模型、檢索策略、回答格式與策略參數；評測模型、評分模式及最大並行數為全域設定。

## 實驗組參數

選擇策略後，卡片只顯示該策略可用的控制項。數值會保存於各實驗組的策略設定，切換策略後再次切回仍會保留。參數預設值依目前 GraphRAG 3.2 設定；設定變更會套用到該組的查詢。

### Local

- Community 層級：指定查詢使用的社群層級。
- 原文片段比例、社群報告比例：控制 Local Context 由兩類資料分配的比例。
- 對話歷史輪數：限制送入查詢的歷史對話輪數。
- 相關實體數、相關關係數：限制局部查詢映射的實體與關係數量。
- 最大上下文 Token：局部查詢上下文大小上限。

### Global

- Community 層級：選擇社群報告層級。
- 最大上下文 Token、Map 階段資料 Token 上限：限制 Global Context 與 Map 輸入資料量。
- Map 回答長度上限、Reduce 回答長度上限：限制分段分析及最後整合輸出的長度。
- 啟用動態社群選擇：開啟後才顯示動態搜尋的門檻、父層保留、重複評估次數、摘要使用方式和最高層級設定。

### DRIFT

- Community 層級、探索深度、每輪 Follow-up 上限、Primer 報告分組數。
- 原文片段比例、社群報告比例：分配 DRIFT 局部搜尋使用的 Context 類型。
- 局部搜尋實體數、關係數、每輪最大上下文 Token、每輪候選回答數。
- 每輪回答 Temperature、Top P：控制 DRIFT 局部回答的取樣設定；這是 GraphRAG DRIFT 策略參數，並非一般回答模型的共用欄位。

### Basic

- 取回文字片段數（k）：Basic 搜尋放入上下文的 Text Units 數量。
- 最大上下文 Token：Basic 搜尋上下文大小上限。

本頁不提供 Reranker 或證據擴展等非此專案策略控制項。GraphRAG 不同版本的設定支援可能變動；本介面欄位依專案安裝的 3.2.x 版本實作。

## 執行與評測

每個題目會先呼叫所選策略檢索並產生回答，再由全域評測模型比較實際回答和標準答案。嚴格／寬鬆評分模式可在頁面設定。頁面顯示 0 錯誤、1 部分對、2 全對；可人工修改逐題等級，摘要分數會重新計算。

執行中可查看即時進度並停止。停止後已完成題目與部分摘要會保存；組別設定、題目集和最近一次實驗結果在重新開啟相同專案時還原。

## 檢索來源指標

目前來源指標依可用的來源資料計算：

- Evidence Hit Rate：有 Gold Evidence 的題目中，至少取回一個標註文件／頁面的題目比例。
- Evidence Precision：先逐題計算「命中的不同文件＋頁面來源數 ÷ 取回的不同文件＋頁面來源數」，再對有 Gold Evidence 的題目平均；重複 chunk 同文件同頁只算一次。無 Gold 頁碼者排除，有 Gold 但沒有取回來源者該題為 0。
- Document Hit Rate：取回來源文件至少命中一份 Gold 文件的題目比例。

來源會以文件識別及頁碼比對，而非 chunk ID。指標只在策略回傳且程式能可靠解析來源時提供。若沒有排序後的來源排名或文件頁碼無法映射，指標會標示不可計算；Global 的社群報告目前尚無法可靠映射到原始文件，因此不虛構來源命中。

## 匯出結果

- `retrieval-experiment-summary.json`：精簡摘要，包含專案、評測設定、總結、各組參數和各組摘要。
- `retrieval-experiment-details.json`：包含執行狀態、題目集資訊及所有逐題結果。

兩份結果均保存在專案 `exports/` 目錄。題目集匯入格式見[題目集 JSON 格式](題目集格式.md)及[可用範例](檢索實驗格式範例.json)。
