# 題目集 JSON 格式

「3 自動問答測試」與「4 檢索實驗」使用同一種 JSON 題目集格式。根節點包含 `questions` 陣列，每題需有題號、題目和標準答案；題目來源與答案來源分開記錄。沒有可確認來源時，可使用空陣列。

```json
{
  "questions": [
    {
      "number": 1,
      "question": "發生紙張卡住時，開啟後蓋前要注意什麼？",
      "expected_answer": "若剛完成列印，定影器及周圍部件可能很燙，應避免觸碰。",
      "answer_aliases": ["剛列印後定影器和周圍部件可能仍然高溫，請勿觸摸。"],
      "question_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96]
        }
      ],
      "answer_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96, 97]
        }
      ]
    }
  ]
}
```

欄位規則：

- `number`：正整數題號，不能重複。
- `question`、`expected_answer`：非空字串。
- `answer_aliases`：選填字串陣列，列出可接受的其他標準答案；未提供時預設為空陣列，EM／F1 僅比對 `expected_answer`。
- `question_sources`、`answer_sources`：來源陣列。每筆來源使用 `document_name` 和非空正整數 `pages` 陣列配對；同一來源可以跨頁，也可以列出多份文件。為相容 Neo4j-DEMO 匯出檔，根節點可帶 `schema_version`、來源物件可帶 `document_id`，匯入時皆會忽略。
- `question_sources` 記錄題目內容的來源；`answer_sources` 記錄標準答案依據，兩者可以不同。
- 不支援舊欄位格式或未列出的額外欄位。請以範例檔 [`docs/檢索實驗格式範例.json`](檢索實驗格式範例.json) 為準。

匯入多個題目集時，系統保留資料集識別以供結果分組。「4 檢索實驗」再次匯入時會取代目前載入的題目集，不會把舊題目繼續累加。
