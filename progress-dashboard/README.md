# 開發進度指揮中心

以策略遊戲風格的 3D 地圖呈現本 repo 的開發進度。使用 Next.js（App Router）與 React Three Fiber，由伺服器端直接讀取上一層 repo 的檔案與 git，畫面每 20 秒自動更新。

## 啟動

需要 Node.js 20 以上（本機以 nvm 安裝的 v24 驗證）。

```bash
cd progress-dashboard
npm install
npm run dev          # 開發模式：http://127.0.0.1:3100
# 或
npm run build && npm start
```

預設讀取上一層目錄；要指向其他 checkout 時設定 `REPO_ROOT=/path/to/repo`。伺服器只綁定 127.0.0.1，因為「執行測試」會在本機執行 pytest。

## 地圖元素與資料來源

視覺上採用明亮的等角（正交）積木風格：白色圓角卡片、藍色主色、低多邊形 3D 模型，比喻為「開發工地」。

| 元素 | 意義 | 資料來源 |
|---|---|---|
| 分區與地塊 | 每個改善項目一塊地，依類別第一段分區；分區以格狀重劃排成街廓，四周都是街道，街廓空地是公園 | `docs/改善計畫.md` 狀態總覽表格 |
| 藍色倉庫 | 完成；橘點＝已完成但未提交；大小依優先度 | 同上 |
| 鷹架＋塔吊＋堆高機 | 進行中 | 同上 |
| 棧板與交通錐 | 待辦；待確認另插黃色定位圖釘 | 同上 |
| 測試貨櫃場 | 每個測試模組一個貨櫃，通過為青綠、失敗為紅色並插紅色圖釘 | 按「執行 pytest」以 `.venv/bin/python -m pytest` 執行，結果快取於 `.cache/tests.json` |
| 路上的卡車 | 最近 7 天的提交（3～8 台），貨櫃色帶代表提交類型；在路網上行駛，每隔一陣子沿最短路線開進「Git 倉庫」卸貨 | `git log --shortstat` |
| 路網與號誌 | 棋盤式街道、斑馬線與停止線；路口號誌各方向輪流綠燈（含黃燈與全紅清道） | 裝飾（車流模擬） |
| Git 倉庫 | 外圍住宅帶的一整塊街廓，兩條穿越式卸貨道：捲門打開→卡車開進去卸貨 5 秒→從另一端開出、讓行後匯入；門上燈號綠＝空、黃＝進出、紅＝卸貨，屋頂看板顯示使用中的卸貨道 | 裝飾（車流模擬） |
| 城鎮與車流 | 外圍住宅街廓沿街的住宅、商店、辦公樓（正面朝街）與後院樹木；小客車與廂型車在路網上靠右行駛、路口隨機轉彎、保持跟車距離且不堵塞路口，被選取停下的卡車後方會排隊 | 裝飾（以座標雜湊產生，結果固定） |
| KPI 卡、導覽列 | 計畫完成、測試通過、本週提交、分支與未提交變更 | 同上與 `git status --porcelain` |
| 任務追蹤 | 待開工 → 施工中 → 完工 → 已提交 的流程；未選取時顯示各階段數量 | 改善計畫狀態與「結果」欄的 commit／未提交標記 |
| 交接・建議下一步、交接分頁 | 「目前狀態」段落 | `docs/交接紀錄.md` |

點擊地塊、貨櫃、卡車或表格列會讓鏡頭移過去並在右側卡片顯示細節；右側地圖控制可縮放、旋轉 45° 與回到全景。任務分頁的狀態徽章可篩選地塊。

選取的物件會出現藍色角框與浮動標籤；選取卡車後可按「鏡頭跟隨卡車」或 `F` 讓鏡頭持續跟著它，拖曳地圖即結束跟隨。導覽列的鈴鐺列出需要注意的項目（失敗測試、待確認、已完成未提交、未提交變更），以及開啟頁面後偵測到的新提交、狀態變更與測試結果；這些動態也會在畫面上方短暫提示，點一下即可跳到對應物件。

| 快捷鍵 | 動作 |
|---|---|
| `/` | 搜尋 |
| `Esc` | 關閉通知選單或取消選取 |
| `Space` | 暫停／繼續動畫（暫停時只在鏡頭或資料變動時重繪；系統設定「減少動態」時預設暫停） |
| `F` | 跟隨／停止跟隨選取的卡車 |

## 測試

```bash
npm test             # vitest：Markdown／git／JUnit 解析、地圖版面、通知、車流與城鎮模擬
npm run typecheck
```

## 與「5 3D 儀表板」共用的世界模擬

格狀重劃（`packBlocks`）、路網與號誌、城鎮、車流與物流倉庫的邏輯都在 `lib/world.ts`（純計算，畫面元件只讀結果）。管理後台的「5 3D 儀表板」（`src/automotive_graphrag/dashboard3d.py`）沒有建置流程，改用 Node 內建的型別剝除把這個檔案轉成 `src/automotive_graphrag/dashboard_world.py` 內嵌使用。修改 `lib/world.ts` 後執行：

```bash
npm run export-world
```

`tests/world-export.test.ts` 會檢查兩份是否同步。
